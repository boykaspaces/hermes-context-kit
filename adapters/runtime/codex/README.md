# Codex Runtime Adapter

Use this adapter when Codex operates a Context Kit project. Initialization with
`--runtime-adapter codex` adds an `AGENTS.md` entry point from the adapter
template. The portable core does not require that filename.

Install common Skills through Codex's supported Skill mechanism. Runtime paths
and user-local configuration remain outside the project manifest.

Use [`SKILL_AUTHORING.md`](./SKILL_AUTHORING.md) when rendering or installing a
reusable Skill for Codex.
